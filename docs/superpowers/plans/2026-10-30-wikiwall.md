# WikiWall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows desktop app that puts a different high-quality Italian Wikipedia article on the wallpaper, refreshing on login/unlock, when the desktop is shown, and at a configurable interval.

**Architecture:** A Python package with a small CLI. It fetches the curated quality-article lists from Italian Wikipedia, picks an unseen title, renders an editorial HTML layout to a PNG with headless Chromium (Playwright), and sets it as the Windows wallpaper. A background watcher with a tray icon handles refresh triggers. Everything is local and cache-backed.

**Tech Stack:** Python 3.12, requests, Playwright (Chromium), Pillow, pystray, qrcode, pytest.

**Spec:** `docs/superpowers/plans/2026-10-30-wikiwall.md` (this document is the design + plan).

## Global Constraints

- Windows 10/11 primary target; code must import safely on other platforms.
- Italian Wikipedia (`it.wikipedia.org`) by default; language configurable.
- Quality sources: `Wikipedia:Vetrina` and `Wikipedia:Voci di qualità` (namespace 0 links only).
- Never show the same article twice within the last `history_size` (default 50).
- Cache the quality list for 7 days; fall back to the last successful article when offline.
- All generated files live under `%LOCALAPPDATA%\WikiWall` unless `WIKIWALL_HOME` is set.
- The app must be usable without a GUI: `wikiwall next` works from a terminal.
- Attribution "Testo e immagini: Wikipedia · CC BY-SA 4.0" is always rendered on the wallpaper.
- No secrets, no telemetry, no Wikimedia account.

## Review Focus

- Network failure or HTTP 429 while fetching the quality list or summary: must use cache/last article and log, never crash the watcher.
- Very long title or extract: must reduce font size / truncate at a sentence boundary, never overflow the canvas.
- Article without a lead image: must render the gradient/initial fallback, not a broken image.
- Missing Playwright browser: `wikiwall next` must print an actionable message (`wikiwall setup`).
- Rapid triggers (unlock + desktop + interval): debounce so only one render happens per cooldown window.
- Repeats: history must be written only after a successful render, and must be respected on the next pick.

### Task 2: Wikipedia quality client

**Files:**
- Create: `src/wikiwall/wikipedia.py`
- Test: `tests/test_wikipedia.py`

**Interfaces:**
- Consumes: `cache_dir()`, `History`.
- Produces:
  ```python
  @dataclass(frozen=True)
  class Article:
      title: str
      description: str
      extract: str
      url: str
      image_url: str | None
      quality: str

  class WikipediaClient:
      def __init__(self, language: str = "it", cache_dir: Path | None = None, timeout: float = 30.0)
      def quality_titles(self, refresh: bool = False) -> list[tuple[str, str]]
      def random_article(self, recent: Sequence[str] = (), rng: random.Random | None = None) -> Article
      def summary(self, title: str) -> Article
  ```
- Quality map: `("it", "Wikipedia:Vetrina", "vetrina")`, `("it", "Wikipedia:Voci di qualità", "qualità")`.
- Use `action=parse&prop=links&format=json&formatversion=2`; keep `ns == 0`; drop titles containing `:`; dedupe; vetrina wins.
- Cache `quality.json` with `fetched_at` and `items`.
- On 429: retry with `Retry-After` up to 3 times, then use stale cache.
- `random_article`: 65% vetrina / 35% qualità when both available; excludes `recent`; retries up to 5 summaries.

  ```python

  class Watcher:
  ```

- CLI: `next` (options `--theme`, `--width`, `--height`, `--output`, `--no-set`), `watch` (`--no-tray`), `install`, `uninstall`, `config`, `history`, `setup`, `--version`.
- Watcher triggers: idle return (idle >= 5 min, then active), desktop foreground for 3s (cooldown 10 min), interval 60 min, tray "Cambia ora". Debounce 2 min between changes.
- Tray menu: Cambia ora / Apri voce / Pausa / Esci.
- `install` writes `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\WikiWall.vbs` running `pythonw -m wikiwall watch` with the project cwd; `uninstall` removes it.
- Log to `%LOCALAPPDATA%\WikiWall\wikiwall.log` (rotating).
- Offline fallback: `WikipediaClient` raises → load `last_article.json` and re-render.
